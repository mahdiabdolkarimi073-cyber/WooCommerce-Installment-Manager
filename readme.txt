=== WooCommerce Installment Payment ===

نسخه: 1.0.0
نویسنده: Your Name

== توضیحات ==

افزونه «پرداخت اقساطی ووکامرس» به شما امکان می‌دهد محصولات خود را به‌صورت اقساطی به مشتریان عرضه کنید. با این افزونه می‌توانید:

* پیش‌پرداخت (به‌صورت درصدی یا مبلغ ثابت) تعیین کنید
* تعداد اقساط یا تعداد ماه را مشخص کنید
* کارمزد اقساط (به‌صورت درصدی یا مبلغ ثابت) تعیین کنید
* تنظیمات را به‌صورت سراسری یا اختصاصی برای هر محصول اعمال کنید

== پیش‌نیازها ==

* وردپرس نسخه 5.0 یا بالاتر
* ووکامرس نسخه 5.0 یا بالاتر
* PHP نسخه 7.2 یا بالاتر

== نصب ==

1. فایل zip افزونه را دانلود کنید.
2. وارد پیشخوان وردپرس شوید و به مسیر «افزونه‌ها → افزودن جدید» بروید.
3. روی دکمه «بارگذاری افزونه» کلیک کنید و فایل zip را انتخاب کنید.
4. روی «هم‌اکنون نصب کن» کلیک کنید.
5. پس از نصب، افزونه را فعال کنید.

روش جایگزین (دستی):

1. فایل zip را از حالت فشرده خارج کنید.
2. پوشه wc-installment-payment را در مسیر wp-content/plugins/ روی هاست خود کپی کنید.
3. وارد پیشخوان وردپرس شوید و به مسیر «افزونه‌ها» بروید.
4. افزونه «WooCommerce Installment Payment» را فعال کنید.

توجه: برای فعال‌سازی این افزونه، ابتدا باید ووکامرس نصب و فعال باشد. در صورت عدم فعال‌سازی ووکامرس، افزونه به‌صورت خودکار غیرفعال می‌شود و پیام هشدار نمایش داده می‌شود.

== تنظیمات سراسری ==

پس از فعال‌سازی افزونه، به مسیر «ووکامرس → تنظیمات → پرداخت اقساطی» بروید. در این بخش می‌توانید تنظیمات پیش‌فرض زیر را مشخص کنید:

* فعال/غیرفعال کردن افزونه به‌صورت سراسری
* نوع پیش‌پرداخت (درصدی یا مبلغ ثابت)
* مقدار پیش‌پرداخت پیش‌فرض
* روش قسط‌بندی (تعداد اقساط یا تعداد ماه)
* تعداد اقساط یا ماه پیش‌فرض
* نوع کارمزد (درصدی یا مبلغ ثابت)
* مقدار کارمزد پیش‌فرض

== تنظیمات اختصاصی هر محصول ==

در صفحه ویرایش هر محصول، در بخش «اطلاعات محصول»، تب جدیدی به نام «پرداخت اقساطی» اضافه می‌شود. در این تب می‌توانید:

* فروش اقساطی را برای محصول مورد نظر فعال کنید
* انتخاب کنید که آیا می‌خواهید از تنظیمات سراسری استفاده کنید یا تنظیمات اختصاصی تعیین کنید
* در صورت انتخاب تنظیمات اختصاصی، تمام پارامترها (پیش‌پرداخت، تعداد اقساط، کارمزد) را به‌صورت جداگانه برای این محصول مشخص کنید

== نمایش در صفحه محصول ==

در صفحه نمایش تک‌محصول، اگر فروش اقساطی برای آن محصول فعال باشد، کادری نمایش داده می‌شود که شامل موارد زیر است:

* مبلغ پیش‌پرداخت
* مبلغ هر قسط
* تعداد اقساط یا ماه
* کارمزد
* مبلغ کل قابل پرداخت

== صفحه تسویه حساب ==

در صفحه سبد خرید و تسویه حساب، برای محصولات اقساطی، خلاصه‌ای از اطلاعات پرداخت اقساطی نمایش داده می‌شود. پس از ثبت سفارش، اطلاعات اقساط در سفارش ذخیره می‌شود.

== نمایش در پیشخوان مدیریت ==

در صفحه جزئیات سفارش در پیشخوان وردپرس، کادری به نام «جزئیات اقساط» نمایش داده می‌شود که شامل تمام اطلاعات ذخیره‌شده مربوط به پرداخت اقساطی آن سفارش است.

== سوالات متداول ==

= آیا این افزونه با ووکامرس جدید سازگار است؟ =
بله، این افزونه با ووکامرس نسخه 5.0 به بالا سازگار است و از سیستم HPOS (High-Performance Order Storage) پشتیبانی می‌کند.

= آیا می‌توانم برای هر محصول تنظیمات متفاوت تعیین کنم؟ =
بله، در تب «پرداخت اقساطی» هر محصول می‌توانید تنظیمات اختصاصی تعیین کنید یا از تنظیمات سراسری استفاده کنید.

= آیا اعداد به فارسی نمایش داده می‌شوند؟ =
بله، تمام اعداد و مبالغ به‌صورت فارسی و با فرمت تومان نمایش داده می‌شوند.
